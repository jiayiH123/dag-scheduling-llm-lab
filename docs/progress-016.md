# 几个百分点是否值得做，以及教师到底是什么

2026-10-15；外循环35：文献和代码核对，无新训练、神经推理或求解器调用。

## 对当前空间的判断

上一表是每格64个7–10任务小图的教师至OPT空间，不代表20/40/80任务主实验都只有这个空间。容易小图CCR1/预算不限制仅0.55%，在同一分布上要求再提高5%确实不现实。另一方面，较大诊断中教师在两档受限预算下至少还有12.28%/10.89%的均值空间，但只有12个基础图，不能推广为整个目标分布或当前神经策略可达性。

必须区分全局OPT、固定HEFT构造顺序下所有可行映射的最好值、当前教师、当前学生。前两者的差距尚未量化。固定构造顺序不意味着任务串行执行；单次forward也不强制必须沿用HEFT顺序。可以研究一次输出优先级与设备评分，仍需满足一次构造和共同约束。

## 教师不是另一个神经模型

用户提出的第二种理解准确：在相同训练实例上运行多种规则，重放设备映射并选优，加64次局部修改尝试，得到动作伪标签，再训练学生。预算是硬约束，优先最小makespan，费用仅同makespan时打破平局。不是同时无条件取费用最低和时间最短，也不是所有调研方法都已实现。

原800个训练配置提供36540个任务→资源池标签，训练/验证/测试按底层图身份隔离。没有独立训练的教师网络，没有教师参数拷贝，没有软logits知识蒸馏，没有用求解器提供OPT标签。学生通过交叉熵反向传播学习参数，之后PPO更新。保留的PPO配方仍含系数0.02的教师动作模仿项；它是否影响超过教师，需要单独对照验证，不能直接断言原因。

## 下一步建议

继续有依据，但先测固定构造顺序下的映射优化空间，以及学生至教师损失。若足够，再改训练目标、模仿权重和探索；若主要空间来自顺序限制，则考虑一次forward同时输出顺序与设备信息。对强基线稳定3–5%可作为有意义的工程目标，不是会议录用门槛。所有影响指标的组件、推理次数和压力数据生成规则需披露。
