# 当前项目交接

本包时间2026-10-15。主任务是通信/预算/资源联合约束的单次forward调度，最终看全局makespan。LLM路线仍是待验证方案；没有远程模型调用或已训练LLM。

## 正确的问题与基线

任务非抢占；资源池允许累计需求不超过容量的任务并行；任务执行时间向上取整；跨池通信是固定data/bandwidth延迟，可重叠，无链路争用；费用是duration*rate，硬总预算。详见原PDF和vendor/legacy_comm_core.py、budget_core.py，不能偷偷切换到无限VM/serverless或串行处理器再混比。

合成平台speed[1,2,4],price[1,4,16]；serial容量[1,1,1]、demand1；pool容量[3,4,4]、demand1–4。四族pipeline/forkjoin/costly_downstream/random_packing；CCR训练含0/.1/1/5，验证/测试0/1/5；预算Bmin+eta*(Bfast−Bmin)，eta1/.6/.25。较紧预算是额外升级预算的25%，不是总预算的25%。

## 网络与教师

当前GNN：任务×设备乘积图、每对12维数值特征、2层双向消息传递、14946参数。一次forward输出a,w；LOCAL解码采用a+w*局部升级费用比例−归一化EFT，按固定HEFTrank顺序构造，硬预算reserve和资源日历处理动态状态。固定构造顺序不意味着任务串行执行。

教师：HEFT/PEFT/JoinLookahead/CostFirst/MSLBLadapted与5种PEFT价格惩罚，共10候选。各候选映射按固定HEFT顺序重放，按(makespan,cost)字典序选优，再64次随机1/2任务改池尝试。不是64次成功改进，也不保证最优或收敛。它是专家程序而非网络，BC学动作，不拷贝教师权重。PPO仍有.02模仿项，是否影响突破教师需要对照。

## 两套不同测试集

`reference_dataset`总1448：800train(每图单CCR/预算配置)，216val=24底图×9，432test=48底图×9。按底层latent_id隔离。`known_cycle24_test`是后来独立种子的432配置，供复核周期24/强基线诊断，勿和原test混用。所有携带测试均已看过，不是最终论文盲测。

同一冻结seed11在knowncycle24上，原记录平均逐实例相对改进：Greedy+20.966%、HEFT+15.583%、Randommean5+46.360%；对MSLBL−3.503%、十规则组合−10.091%、教师−12.625%。负值表示学生更差。强基线诊断没有新训练，教师TEST标签仅诊断不能训练。不同fold的百分比不可直接比较成进步。

## 空间与未解决问题

小图OPT审计每格64个7–10任务基础实例；教师在某些容易分布仅剩0.55%，tight25/CCR5剩9.59%。较大12基础图×3预算诊断，教师tight60/tight25可省均值下端12.28%/10.89%，但36配置仅14OPT，其余是上下界；全局OPT可能需要当前固定顺序无法表达的时序。先测固定顺序映射空间和现有训练是否充分，不可把全局空间等同可实现LLM收益。

此前多轮迭代主要建立BC能胜弱基线，RL增量和新模块收益不稳定，未战胜教师/强预算控制。详见archive/findings和evidence。教师超过学生不否定高效压缩路线，但必须报告质量/时间，不能隐去强对照。
